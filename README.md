Sales Report Dashboard – Power BI
This Power BI dashboard provides insights into sales performance including total revenue, top customers, and best-selling products.

Key Features
Total Revenue** – Overall revenue from all sales.
Top 5 Customers** – Who’s bringing in the most money.
Top Products Sold** – Most popular products by sales volume.
Time-based Trends** – Revenue trends across months/years.

Tools & Tech Used
- Power BI Desktop
- DAX for calculations
- Power Query for data transformation
